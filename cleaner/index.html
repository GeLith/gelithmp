常见问题。

为什么杀毒软件可能提示风险？

清理类软件会操作注册表与计划任务，部分杀软会保守提示。本工具行为完全透明，可将程序加入信任区；发布页附有《误报处理指南》。

需要管理员权限吗？

日常清理无需提权。仅当删除受系统保护的启动项时才会弹出 UAC 确认，拒绝后不影响其他功能。

支持哪些系统？

Windows 10（1803+）与 Windows 11。使用系统自带 WebView2 运行时，无需额外安装任何依赖。
